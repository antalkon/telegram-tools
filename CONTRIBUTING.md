# Участие в разработке

Мы рады issue и pull request'ам.

1. Форкните репозиторий и создайте ветку от `main`.
2. Поднимите окружение по [docs/development.md](docs/development.md).
3. Перед PR убедитесь, что проходят проверки:
   ```bash
   cd backend && .venv/bin/python -m pytest
   cd frontend && npm run lint && npm run build
   ```
4. В PR опишите, что меняется и как это проверить. Новую логику, которая ходит в Telegram, покрывайте тестом
   с фейковым клиентом (примеры — в `backend/tests/`).

Правила:

- Пишите в стиле окружающего кода: те же имена, та же плотность комментариев.
- Не коммитьте `.env`, базу (`*.db`), сессии и папку `data/`.
- Изменения схемы БД должны применяться к существующим базам автоматически (см. `_ADDED_COLUMNS` в `app/db.py`).

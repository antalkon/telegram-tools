# Настройки

Все параметры задаются переменными окружения с префиксом `TGT_`. Их можно положить в файл `.env`
(в корне — для Docker Compose, в `backend/` — для локального запуска).

| Переменная | По умолчанию | Описание |
|---|---|---|
| `TGT_ADMIN_PASSWORD` | `admin` | Пароль входа в панель. **Обязательно смените.** |
| `TGT_SECRET_KEY` | — | Длинная случайная строка. Подписывает токены входа и шифрует сохранённые сессии Telegram. Если её сменить, аккаунты придётся подключить заново. Пустое значение не допускается. |
| `TGT_COOKIE_SECURE` | `false` | `true`, если панель открывается по HTTPS. |
| `TGT_DATA_DIR` | `backend/data` (в Docker — `/data`) | Где лежат база SQLite и аватарки. |
| `TGT_TOKEN_TTL_HOURS` | `168` | Сколько живёт вход в панель. |
| `TGT_SCHEDULER_ENABLED` | `true` | Фоновый мониторинг по расписанию. |
| `TGT_FRONTEND_DIST` | `frontend/dist` | Собранный фронтенд, который отдаёт FastAPI. |

Сгенерировать секрет:

```bash
python3 -c "import secrets; print(secrets.token_urlsafe(48))"
```

## Telegram API

`api_id` и `api_hash` в переменные окружения не кладутся. Их вводят в панели при подключении аккаунта
(**Аккаунты → Добавить**). Получить их можно на [my.telegram.org/apps](https://my.telegram.org/apps).

Строка сессии хранится в базе в зашифрованном виде (Fernet, ключ берётся из `TGT_SECRET_KEY`).

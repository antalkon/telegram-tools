# TG Toolkit — Telegram-парсер комментаторов, индексатор чатов и аналитика аудитории

**Self-hosted веб-панель для OSINT и аналитики Telegram:** сбор всех комментаторов канала, индексация истории
групп и форумов, полнотекстовый поиск по сообщениям, пересечения аудиторий, граф связей и поиск каналов
(ТГК) и чатов людей из базы.

Панель работает через **MTProto** ([Telethon](https://github.com/LonamiWebs/Telethon)) от имени вашего
пользовательского аккаунта: Bot API не умеет читать историю чужих каналов. Всё хранится у вас: один контейнер
и SQLite, без облачных сервисов.

## Возможности

### Сбор данных

- **Сборщик комментаторов канала.** Вставляете ссылку на канал и получаете всех, кто когда-либо
  комментировал его посты. Для каждого: аватар, имя, @username, ID, Premium/бот/удалён, число комментариев
  и прокомментированных постов, первый и последний комментарий.
- **Индексатор чатов.** Группы, супергруппы, форумы, чаты обсуждений. Сохраняет всю историю
  (или с даты / последние N сообщений) с авторами, ответами и темами. Собирает список участников,
  если админы его не скрыли.
- **Каналы пользователей.** Находит ТГК и чаты людей из базы:
  - личный канал, закреплённый в профиле;
  - ссылки в bio (`t.me/…`, `t.me/+invite`, `name.t.me`, `tg://`);
  - `@упоминания` в bio — остаются только каналы и чаты, люди отсеиваются;
  - каналы, от имени которых люди пишут.

  Найденное можно проиндексировать в один клик.
- **Источники.** Каналы и чаты в одном списке. Доступны действия:
  - **дозабор** — только новое с прошлого сбора;
  - **переиндексация** с другими параметрами;
  - **мониторинг** по расписанию с уведомлениями в панель и в Telegram;
  - **скрытие** из аналитики.

### Поиск и аналитика

- **Полнотекстовый поиск** (SQLite FTS5) по всем комментариям и сообщениям:
  - «фразы» в кавычках, `-исключения`;
  - фильтры по источнику, автору и датам;
  - контекст вокруг найденного сообщения, «кто чаще пишет об этом»;
  - люди, у которых запрос найден в метаданных или в прикреплённых PDF.
- **Пользователи** — все люди, объединённые по источникам. Фильтры «есть в 2+/3+ источниках»,
  «писали / молчуны»; метки, заметки, избранное.
- **Досье пользователя:**
  - граф связей и место в рейтинге каждого канала;
  - тепловая карта «день × час»;
  - лента комментариев, bio и каналы человека;
  - индекс подозрительности: повторы, ссылки, всплески;
  - **метаданные**, внесённые вручную: ФИО, email, телефон, страна, город, адрес, паспорт;
  - **PDF-документы** к профилю: текст из них индексируется.
- **Аналитика канала:**
  - динамика обсуждений;
  - новые и вернувшиеся комментаторы, концентрация активности;
  - топ-посты и пересечения с другими каналами.
- **Пересечения аудиторий** — матрица общих комментаторов между каналами.
- **Граф связей** — интерактивная карта «люди ↔ каналы» и «каналы ↔ каналы».
- **Экспорт** в XLSX / CSV / JSON почти из любого списка.
- **Избранное:** звёздочка у людей, источников и каналов. У избранного своя страница, в списках оно показывается первым.
- **Перенос данных:** полный экспорт в один ZIP (с аватарками и, по желанию, сессиями Telegram), импорт сюда или в
  другую панель — полная замена, объединение с сохранением своего или с заменой совпадений — и очистка всех данных
  с резервной копией.

### Обогащение данных

- **История профилей:** смена имени, username, фото, bio и телефона между сборами; примерный возраст аккаунта по ID.
- **Посты каналов** с просмотрами, репостами и маркировкой рекламы (erid, ИНН рекламодателя) — через аккаунт
  или **без аккаунта**, через публичную веб-версию `t.me/s/`.
- **Контакты:** телефоны, email, сайты, крипто-кошельки, ИНН/ОГРН из bio, сообщений, описаний каналов и постов;
  карточка компании из **ЕГРЮЛ/ЕГРИП** по ИНН.
- **Больше каналов:** откуда репостят, кого упоминают в сообщениях, «похожие каналы» Telegram.
- **Username на других сайтах:** ~600 публичных сайтов по базе WhatsMyName.
- **PDF-отчёты** по человеку и источнику, **экспорт графа** в GEXF и GraphML (Gephi, yEd, Maltego).

### API и ИИ-агенты

- **HTTP API**: всё, что умеет панель. Документация на [Scalar](https://scalar.com) по адресу `/api/docs`
  (OpenAPI 3.1), закрыта логином.
- **MCP-сервер** на `/mcp`: Claude Code, Claude Desktop, Cursor и другие агенты ищут по базе, читают профили
  и аналитику, ведут метки и метаданные, запускают сборы.
- **API-токены** создаются в настройках: «только чтение» или «полный доступ», можно задать срок действия
  и отозвать в любой момент.

### Надёжность

- Аккуратная работа с лимитами Telegram:
  - профиль нагрузки в настройках: «Стандартный» (максимальная скорость, как раньше), «Оптимизированный» (паузы
    между запросами и задачами, адаптивное замедление после FloodWait) или свои значения для каждого типа запросов;
  - журнал FloodWait по методам — чтобы понять, что именно упирается в лимиты;
  - FloodWait показывается обратным отсчётом, задача продолжает с места остановки;
  - блокировки отдельных методов паркуются, остальное продолжает собираться;
  - кэш аватарок и результатов запросов.
- Сессии Telegram хранятся в базе зашифрованными. Вход в панель — по паролю, JWT в httpOnly cookie.
- Мультиплатформенный Docker-образ (amd64 / arm64) с healthcheck. Процесс в контейнере работает не от root.

## Быстрый старт (Docker)

```bash
git clone https://github.com/antalkon/telegram-tools.git && cd telegram-tools
cp .env.example .env
# впишите в .env пароль панели и секрет:
#   TGT_ADMIN_PASSWORD=...
#   TGT_SECRET_KEY=$(python3 -c "import secrets;print(secrets.token_urlsafe(48))")
docker compose up -d
```

Откройте http://127.0.0.1:8000 и войдите с паролем из `.env`.

Или одной командой:

```bash
docker run -d --name tg-toolkit -p 127.0.0.1:8000:8000 -v tgt-data:/data \
  -e TGT_ADMIN_PASSWORD='пароль' -e TGT_SECRET_KEY='длинная-случайная-строка' \
  ghcr.io/antalkon/telegram-tools:latest
```

HTTPS, reverse proxy, бэкапы и обновление описаны в [docs/deployment.md](docs/deployment.md).

## Подключение аккаунта Telegram

1. Получите `api_id` и `api_hash` на [my.telegram.org/apps](https://my.telegram.org/apps).
2. В панели откройте **Аккаунты → Добавить**, введите телефон, код из Telegram и пароль 2FA, если он включён.
3. Сессия сохранится в базе, зашифрованная ключом `TGT_SECRET_KEY`.

> Используйте отдельный аккаунт. Интенсивный сбор может приводить к FloodWait и ограничениям со стороны Telegram.

## Разработка

```bash
cd backend && python3 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/uvicorn app.main:app --reload --port 8000
cd frontend && npm install && npm run dev   # http://localhost:5173
```

Подробнее, в том числе про демо-данные без Telegram: [docs/development.md](docs/development.md).

## Ответственное использование

Панель собирает только то, что видно подключённому аккаунту: публичные каналы, группы, где он состоит,
и публичные профили. Соблюдайте [Условия использования Telegram API](https://core.telegram.org/api/terms)
и законы о персональных данных своей страны. Не используйте инструмент для спама, травли или слежки.
